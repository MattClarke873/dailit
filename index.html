Dropbox sync

Everything saves on this phone first. With signal, it copies to your Dropbox so the log and kit are safe and match on other devices.

Connect Dropbox
  1. On dropbox.com/developers, press Create app. Pick Scoped access and App folder. Name it anything.
  2. Permissions tab: tick files.content.read and files.content.write, then Submit.
  3. Settings tab: copy the App key and paste it below.
  4. Press Get code, sign in and press Allow. Copy the code Dropbox shows.
  5. Come back here, paste the code and press Link.
Get code

Link from the home screen app, so the connection is saved there.

Backup

A backup file holds your rifles, ammo and stock history, log, dope and chrono. Keep it in Files, iCloud or email it to yourself. Restoring adds it to what is on this phone; newer changes win, so nothing newer is lost.
